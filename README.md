# AI-Powered Code Reviewer and Quality Assistant

## 📌 Project Overview

The **AI-Powered Code Reviewer and Quality Assistant** is an intelligent web application developed as part of the **Infosys Internship Project**. It helps developers improve code quality by automatically analyzing source code, identifying potential issues, and generating AI-powered suggestions for better readability, maintainability, and overall software quality.

The application combines traditional static code analysis with Natural Language Processing (NLP) techniques to provide meaningful code reviews and quality recommendations.

---

## 🎯 Objectives

* Automate the code review process.
* Improve code readability and maintainability.
* Detect coding issues and quality concerns.
* Generate AI-based improvement suggestions.
* Assist developers in writing cleaner and more efficient code.

## 🚀 How It Works

1. Upload or paste the source code.
2. The application preprocesses the code.
3. Static analysis is performed using Python AST.
4. AI models evaluate code quality.
5. Similarity analysis is performed.
6. The system generates quality metrics and suggestions.
7. The final review report is displayed to the user.
